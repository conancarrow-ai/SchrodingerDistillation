{\scriptsize {\scshape Fan-in.} A sparse linear layer $S:\R^{n_{\mathrm{in}}}\to\R^{n_{\mathrm{out}}}$ with fan-in $K$ computes $S(x)=(M\odot W)x+b$, $M\in\{0,1\}^{n_{\mathrm{out}}\times n_{\mathrm{in}}}$ with $K$ ones per row drawn uniformly without replacement ($1\le K\le n_{\mathrm{in}}$; $K=n_{\mathrm{in}}$ is the dense map; the masked dense weight and the $n_{\mathrm{out}}\times K$ weight with an index table are two implementations of the same map). $K$ fixes in-degrees, not the maximum degree $K_G$ of the network graph: with $k^-_i=\sum_j M_{ij}=K$ for every output unit $i$ and $d^+_j=\sum_i M_{ij}$ for every input unit $j$,
\[
\mathbb E\,d^+_j=\frac{n_{\mathrm{out}}K}{n_{\mathrm{in}}},\qquad k_v=K_{l(v)}+d^+_v \text{ for a hidden unit } v \text{ of layer } l(v),\qquad K_G:=\max_v k_v\;\ge\;\max_l K_l,
\]
with equality only for supports without reuse, which random supports do not enforce. The fan-in $K$ (per layer, $K_l$) is the quantity of interest; a green box is such a map for any $K\le n_{\mathrm{in}}$.}
